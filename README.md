## 📌 Project Overview
InvoSureAI is an intelligent decision-support tool designed for Indian MSMEs. It automates the extraction of data from unstructured invoices (images/PDFs) and provides proactive GST compliance checks, such as GSTIN validation and tax calculation verification, before the final filing process.

## 🛠️ Tech Stack (Current & Planned)
* **Frontend:** HTML5, CSS3 (Bootstrap 5), JavaScript (Vanilla), FontAwesome 6.
* **Backend (Planned):** Python (FastAPI/Flask).
* **AI/OCR (Planned):** EasyOCR / PaddleOCR, OpenCV, Regex-based Logic Engine.
* **Database (Planned):** MySQL for secure invoice and user record persistence.
